# kwhorne/homebrew-tap

Homebrew formulae for [xpress](https://github.com/kwhorne/xpress) — make
images, video, PDFs and audio smaller.

```sh
brew install kwhorne/tap/xpress           # the command line (macOS, Linux x86_64)
brew install --cask kwhorne/tap/xpress    # the menu-bar app (macOS, Apple silicon and Intel)
```

Video and audio need ffmpeg: `brew install ffmpeg` (the app bundles its own).

Updates: `brew upgrade` (the app also updates itself).

The formula and cask are generated by [`scripts/update.sh`](scripts/update.sh)
from each xpress release's checksums; the *Update* workflow follows new releases
every six hours and the *Test* workflow installs both on macOS and Linux.
